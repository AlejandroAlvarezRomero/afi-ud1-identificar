# afi-ud1-identificar  

Trabajo Alejandro Álvarez Romero 

Este trabajo llamado "Identificar Antes Que Tocar" ha hecho que gestione un caso ficticio sobre como manejar la situación al llegar a la escena antes de empezar a tocar nada, identificando todas las evidencias, etiquetando, llamando a terceros y sobre todo fijándome y cuidando cada mínimo detalle.

Para empezar el trabajo miramos 3 guías diferentes las comparamos viendo cual era el propósito principal de cada una, transmitían como mensaje final lo mismo pero de diferente forma se realizaba, luego vimos las diferencias y las cosas parecidas entre si.

>Esto lo hemos hecho en [Tabla Comparativa](C:\Users\AlejandroAlvarez\afi-ud1-identificar\comparativa.md)

Luego hemos continuado desarrollando una lista de comprobación al llegar a laa escena del problema para ir paso por paso en todas las cosas que hay que hacer, se compone de 17 puntos y de que guía y punto sacamos esa información.

>La podrás encontrar por aquí [Lista de Comprobación](C:\Users\AlejandroAlvarez\afi-ud1-identificar\lista-comprobacion.md)
